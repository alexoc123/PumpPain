Create a web application using React for the domain PumpPain.ie.
The application should take pictures of pump prices sent by users to a number on Whatsapp, let's say for example 50050.
The pictures are then passed through a computer vision system (preferably a cheap one) that takes the numerical values on the pumps and stores them in a database.
Utilising the GPS data given on Whatsapp, the numerical values stored in the database should be linked to the Gas Station closest to where the picture was taken.
The application should then reply back to the user with cheap fuel prices near them.
For the website itself, it should have a home page explaining what the application does with simplicity and then a seperate page that shows a map of the pump prices
